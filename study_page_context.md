# Study Page (study.html) Context

## Purpose
The Study page provides a lightweight, in-browser flashcard reviewing experience for the currently staged deck. It reads from the `localStorage` data generated by the Deck page, allowing users to practice their words immediately without needing to export to Anki first.

## Key Features & Functionality
1. **Data Loading**:
   - On load, it reads `anki_staged_words` and `anki_lang_settings` from `localStorage`.
   - If no words are found, it displays an "Empty Deck" state prompting the user to return to the Deck page.
2. **Flashcard Interface**:
   - Displays a single card at a time with a 3D flip animation.
   - **Front**: Shows the target words (comma-separated if grouped by root) and a main "Play Audio" button.
   - **Back**: Shows detailed information matching the styling of the Anki export (Root badge, part of speech, translations, and examples).
3. **Linear Progression**:
   - Currently implements a simple linear iteration.
   - The user clicks the card (or presses Space/Enter) to flip it and reveal the back.
   - Once flipped, a "Next Card" button appears. Clicking it (or pressing Space/Enter again) advances to the next item.
   - A progress bar and a text counter (e.g., "1 / 5") in the navbar show the user's current position.
4. **Text-to-Speech (TTS)**:
   - Utilizes the browser's native Web Speech API (`window.speechSynthesis`).
   - Clicking "Play Audio" buttons on the front of the card or next to example sentences will read the text aloud in the configured main language.
   - The TTS speed is read from `localStorage` (`tts_speed`), matching the setting from the Deck page.
   - Clicking "Next Card" automatically cancels any currently playing audio.
5. **Completion State**:
   - When the user reaches the end of the deck, the flashcard is hidden, and a completion screen is shown.
   - Users can choose to "Study Again" (resetting the index to 0) or go "Back to Deck".
